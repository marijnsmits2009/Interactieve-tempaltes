# STEM Tutor - Interactieve Componenten

Georganiseerde component library voor het Interactive STEM Tutor project.

## 📁 Mappenstructuur

```
stem-tutor/
├── components/              # De 7 basiscomponenten
│   ├── ExplanationBlock.tsx
│   ├── InteractiveSlider.tsx
│   ├── Quiz.tsx
│   ├── Calculator.tsx
│   ├── StepByStep.tsx
│   ├── Diagram.tsx
│   └── ProgressTracker.tsx
├── docs/                    # Documentatie
│   ├── COMPONENTS.md
│   ├── ARCHITECTURE.md
│   └── USAGE_GUIDE.md
├── examples/                # Praktische voorbeelden per vak
│   ├── wiskunde/
│   ├── biologie/
│   ├── scheikunde/
│   └── etc/
├── config/
│   ├── package.json
│   └── tsconfig.json
└── README.md
```

## 🚀 De 7 Basiscomponenten

1. 📝 **ExplanationBlock** - Uitleg met afbeeldingen
2. 📊 **InteractiveSlider** - Waarden veranderen, resultaat live zien
3. 🎯 **Quiz** - Interactieve vragen met feedback
4. 🔢 **Calculator** - Berekeningen uitvoeren
5. 📋 **StepByStep** - Procedures stap-voor-stap
6. 🎨 **Diagram** - Visualisaties (SVG)
7. ✅ **ProgressTracker** - Voortgang volgen

## ✨ Features

- ✅ Praktische, real-world voorbeelden (geen theorie)
- ✅ Interactief leren
- ✅ Lovable AI integratie
- ✅ Socratische leermethod
- ✅ Voor alle STEM-vakken
- ✅ Oneindig veel variatie met dezelfde componenten
