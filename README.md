# Interactieve Template

Een complete verzameling van interactieve wiskundige visualisaties voor visueel leren. Perfect voor schoolplatformen!

## 📚 Onderdelen

### 📐 Geometrie
- Vormen tekenen en transformeren
- Rotatie, schaal, spiegeling
- Symmetrieën

### 〰️ Golfbeweging
- Sinus- en cosinusfuncties
- Pendelbewegingen
- Harmonische oscillaties

### 🌀 Fractals
- Mandelbrot set
- Julia set
- Recursieve patronen

### 🎯 Fysica
- Projectielbewegingen
- Cirkelbeweging
- Zwaartekracht simulaties

### 📊 Grafieken
- Functiegrafieken
- Real-time plotting
- Interactieve parameters

## 🚀 Hoe te gebruiken

1. Kies een HTML-bestand uit de map
2. Open het in je browser
3. Gebruik de sliders en knoppen om te experimenteren
4. Integreer in Lovable met copy-paste

## 💡 Gebruik in Lovable

Kopieer de code uit elk bestand en plak het in Lovable. Elk bestand is standalone en werkt direct!
